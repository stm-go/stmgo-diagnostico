# Diagnóstico de Segurança Digital — stmgo

Aplicação interna para criação, armazenamento e acompanhamento de diagnósticos de segurança digital.

## Recursos

- autenticação pelo Supabase;
- questionário de segurança;
- importação de CSV;
- cálculo de maturidade;
- recomendações automáticas;
- histórico por usuário;
- busca e filtro;
- paginação;
- abertura, edição e exclusão;
- exportação JSON;
- impressão em PDF.

## Executar

Abra o terminal na pasta do projeto e execute:

```powershell
npm run check
npm test
npm run dev
